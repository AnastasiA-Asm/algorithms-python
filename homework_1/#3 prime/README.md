    Задача 3. Простые числа
Нужно найти количество простых чисел строго меньше N. Простое число больше 1 и делится без остатка только на 1 и само себя.

    Объяснение алгоритма
Перебираю числа от 2 до N - 1. Переменная num в коже - число, которое сейчас проверяется. Если у него находится делитель, кроме 1 и самого числа, оно не простое. Если делитель не найден, увеличиваем счётчик prime_count.

Делители каждого num достаточно проверять до квадратного корня из этого числа, тк у составного числа множители идут парами. Если один множитель больше квадратного корня, второй обязательно меньше него и будет найден раньше.
В коде использую условие divisor * divisor <= num, где знак равенства нужен, чтобы проверить квадратный корень, если он целый. Например, 49 делится на 7, а 7 * 7 = 49

    Оценка сложности
Пусть входное число равно N. Алгоритм тогда рассматривает не более N чисел и при этом для каждого числа он проверяет не более примерно sqrt(N) делителей, поэтому верхняя оценка времени O(N√N)
Дополнительная память - O(1), тк используются только текущее число, делитель и счётчик. Массив чисел алгоритм не создаёт.

    Визуализация работы алгоритма
Вход: N = 12. Проверяем числа от 2 до 11. Само число 12 не проверяем, потому что нужно найти простые числа меньше N

| num | Найденный делитель | Простое? | Счётчик после проверки |
|-----|--------------------|----------|------------------------|
| 2   | -                  | да       | 1                      |
| 3   | -                  | да       | 2                      |
| 4   | 2                  | нет      | 2                      |
| 5   | -                  | да       | 3                      |
| 6   | 2                  | нет      | 3                      |
| 7   | -                  | да       | 4                      |
| 8   | 2                  | нет      | 4                      |
| 9   | 3                  | нет      | 4                      |
| 10  | 2                  | нет      | 4                      |

Простые числа меньше 12: 2, 3, 5, 7, 11. Их пять, поэтому ответ: 5

    Дополнения
В принципе можно искать делители каждого числа вплоть до самого числа, но тогда будет много лишних проверок, поэтому я решила сократить нагрузку проверкой делителей только до квадратного корня
