# Задача 1. Two sum

## Условие

Дан массив целых чисел arr и целое число k. Нужно найти индексы двух разных элементов, сумма которых равна k.

Гарантируется, что подходящая пара ровно одна. В качестве ответа нужно вывести два индекса через пробел в порядке возрастания. Индексы считаются с нуля.

## Объяснение решения

Один из вариантов решения, которое превое пришло на ум - это перебрать все пары элементов и проверить их суммы. Такое решение простое, но при большом массиве потребуется много проверок, поэтому оно работает за O(n²).

Поэтому использую словарь (плюс по теме лекций), который работает на основе хеш-таблицы. Это позволяет быстро проверять, встречалось ли нужное число раньше, без полного перебора предыдущих элементов.

Функция two_sum принимает массив arr и нужную сумму k. Сначала создаётся пустой словарь seen. В нём ключами будут уже встреченные числа, а значениями — их индексы.

Далее массив просматривается слева направо. С помощью встроенной функции enumerate на каждом шаге получаем индекс i и число number. Для текущего числа вычисляем needed = k - number — число, которое нужно найти ему в пару. Например, если сумма должна быть 7, а текущее число равно 4, ему нужна тройка.

Если needed уже есть в словаре, значит, подходящее число встречалось раньше. Его индекс берём из словаря и возвращаем вместе с текущим индексом. Функция возвращает кортеж из двух индексов. Первый индекс будет меньше второго, поскольку он относится к ранее просмотренному элементу.

Если нужного числа в словаре нет, сохраняем текущее число и его индекс, затем продолжаем обход. Если число встречается повторно, сохранённый индекс обновляется. Для поиска пары достаточно помнить один индекс каждого числа.

Важно сначала проверять словарь и только после этого добавлять текущее число. Иначе элемент мог бы найти в словаре сам себя. Например, при текущем числе 3 и сумме 6 нельзя использовать одну тройку дважды. При этом две тройки на разных индексах могли бы образовать подходящую пару.

Когда мы дойдём до второго элемента подходящей пары, первый уже будет сохранён в словаре. Поэтому алгоритм найдёт ответ. После return функция сразу завершится, и оставшиеся элементы проверяться не будут.

В конце функции предусмотрен ValueError, если пара не найдена. Но по условию задачи пара существует, поэтому на допустимых входных данных эта ошибка не возникает.

## Оценка сложности

Пусть n — количество элементов массива. При оценке считаем арифметические операции над числами операциями O(1).

Время работы в среднем — O(n). Массив просматривается один раз, поиск в словаре занимает в среднем O(1), а добавление — амортизированно O(1). То есть отдельное добавление может потребовать расширения словаря, но в среднем на последовательности добавлений его стоимость остаётся постоянной.

В худшем случае при большом числе хеш-коллизий операции со словарём могут занимать O(n), а весь алгоритм — O(n²).

Дополнительная память — O(n). В словаре может храниться количество записей, пропорциональное длине массива.

## Визуализация работы алгоритма

Для визуализации выбран нетривиальный пример, который также включён в тесты:

arr = [4, -6, 7, 4, 0, 9, -5, 3]
k = 2

В массиве есть положительные и отрицательные числа, ноль и повторяющаяся четвёрка. Подходящая пара находится после нескольких шагов.

Изначально словарь seen пуст. В последнем столбце показано его состояние после каждого шага.

| Индекс (i) | Число (number) | Нужное число (needed) | Действие | Словарь seen после шага |
|---:|---:|---:|---|---|
| 0 | 4 | -2 | Числа -2 нет. Запоминаем число 4 и индекс 0 | {4: 0} |
| 1 | -6 | 8 | Числа 8 нет. Запоминаем число -6 и индекс 1 | {4: 0, -6: 1} |
| 2 | 7 | -5 | Числа -5 нет. Запоминаем число 7 и индекс 2 | {4: 0, -6: 1, 7: 2} |
| 3 | 4 | -2 | Числа -2 нет. Обновляем индекс числа 4 на 3 | {4: 3, -6: 1, 7: 2} |
| 4 | 0 | 2 | Числа 2 нет. Запоминаем число 0 и индекс 4 | {4: 3, -6: 1, 7: 2, 0: 4} |
| 5 | 9 | -7 | Числа -7 нет. Запоминаем число 9 и индекс 5 | {4: 3, -6: 1, 7: 2, 0: 4, 9: 5} |
| 6 | -5 | 7 | Число 7 найдено на индексе 2. Возвращаем (2, 6) | {4: 3, -6: 1, 7: 2, 0: 4, 9: 5} |

На индексе 6 текущее число равно -5. Для него нужно число 7, поскольку 2 - (-5) = 7.

Семёрка уже находится в словаре, её индекс — 2. Поэтому функция возвращает (2, 6).

Проверка: arr[2] + arr[6] = 7 + (-5) = 2.

На этом функция завершается. Число -5 в словарь не добавляется, а последний элемент массива уже не обрабатывается.

Ответ: 2 6
