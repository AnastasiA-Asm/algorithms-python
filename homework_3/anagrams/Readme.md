# Задача 2. Anagrams

## Условие

Дан список слов. Нужно сгруппировать слова так, чтобы в одной группе оказались все анаграммы.

Анаграммы содержат одинаковые буквы в одинаковом количестве, но порядок букв может различаться.

## Объяснение решения

Можно сравнивать слова друг с другом и отдельно проверять, являются ли они анаграммами. Но тогда при большом списке потребуется много сравнений. Поэтому по теме использем словарь, чтобы определять группу для каждого слова по общему признаку.

Если отсортировать буквы анаграмм, получится одинаковая строка. Например, слова eat, tea и ate после сортировки букв превращаются в aet. Эту строку можно использовать как ключ словаря, а значением будет список исходных слов.

Функция group_anagrams принимает список words. Сначала создаётся пустой словарь groups, в котором будут собираться группы.

Затем слова перебираются в цикле. Для каждого слова функция sorted сортирует его символы и возвращает список букв. С помощью join эти буквы соединяются в строку без разделителей. Полученная строка сохраняется в переменную key.

Если такого ключа ещё нет в словаре, для него создаётся пустой список. После этого исходное слово добавляется в соответствующую группу с помощью append. Если группа уже существует, новый список не создаётся, а слово добавляется в имеющийся.

Таким образом, анаграммы попадают в одну группу, поскольку получают одинаковый ключ. Слова с разным количеством букв получают разные ключи. Например, aab и abb останутся в разных группах, хотя в обоих словах используются буквы a и b.

Исходные слова сохраняются целиком. Если одно слово встречается несколько раз, все его повторения добавляются в группу. Пустые строки тоже обрабатываются: после сортировки и соединения их ключом остаётся пустая строка.

После обработки всех слов выполняется дополнительная сортировка для удобного вывода. Через groups.values() получаем списки слов и сортируем каждый из них методом sort. Затем функция sorted располагает сами группы по количеству слов с помощью key=len и возвращает готовый список.

Сортировка результата отдельно не требуется в условии, но я подумала, что лучше добавить, чтобы вывод был оформлен так же, как в примере. Группы одинакового размера сохраняют порядок своего появления.

## Оценка сложности

Пусть n — количество слов, m — максимальная длина слова, а g — количество получившихся групп. Для оценок считаем m не меньше 1, чтобы учитывать и пустые строки.

Для каждого слова сортируются его буквы. Это требует до O(m log(m + 1)) времени. Соединение букв в строку и вычисление её хеша требуют O(m). Поэтому группировка всех слов в среднем занимает O(nm log(m + 1)).

Дополнительно сортируются слова внутри групп. В худшем случае сравнение двух строк может потребовать O(m) времени. Суммарное время этой сортировки ограничено O(nm log(n + 1)).

Сортировка самих групп по размеру занимает O(g log(g + 1)), поскольку длина списка определяется за O(1).

Так как g не больше n, общую оценку времени можно записать как O(nm(log(m + 1) + log(n + 1))). Эта оценка учитывает добавленную сортировку результата и предполагает среднюю стоимость операций хеш-таблицы. При большом числе хеш-коллизий работа словаря может быть медленнее.

Дополнительная память: O(n + gm). В группах хранятся ссылки на n исходных слов, а в словаре — g ключей длиной не больше m. Исходные слова не копируются. Верхняя оценка дополнительной памяти — O(nm).

## Визуализация работы алгоритма

Для визуализации выбран нетривиальный пример, который также включён в тесты:

words = ["aab", "tea", "", "abb", "eat", "aba", "bat", "", "bba", "ate", "eat",]

В примере есть несколько групп анаграмм, повторяющееся слово eat, пустые строки и слова с разным количеством одинаковых букв.

Изначально словарь groups пуст. В таблице показано, какая группа изменяется на каждом шаге. На этом этапе слова внутри групп ещё не отсортированы.

| Индекс слова | Исходное слово | Ключ после сортировки букв | Действие | Изменившаяся группа |
|---:|---|---|---|---|
| 0 | "aab" | "aab" | Создаём группу и добавляем слово | ["aab"] |
| 1 | "tea" | "aet" | Создаём группу и добавляем слово | ["tea"] |
| 2 | "" | "" | Создаём группу для пустых строк | [""] |
| 3 | "abb" | "abb" | Создаём группу и добавляем слово | ["abb"] |
| 4 | "eat" | "aet" | Добавляем слово в существующую группу | ["tea", "eat"] |
| 5 | "aba" | "aab" | Добавляем слово в существующую группу | ["aab", "aba"] |
| 6 | "bat" | "abt" | Создаём группу и добавляем слово | ["bat"] |
| 7 | "" | "" | Добавляем ещё одну пустую строку | ["", ""] |
| 8 | "bba" | "abb" | Добавляем слово в существующую группу | ["abb", "bba"] |
| 9 | "ate" | "aet" | Добавляем слово в существующую группу | ["tea", "eat", "ate"] |
| 10 | "eat" | "aet" | Сохраняем повторное вхождение слова | ["tea", "eat", "ate", "eat"] |

После основного цикла словарь содержит:


{"aab": ["aab", "aba"],
"aet": ["tea", "eat", "ate", "eat"],
"": ["", ""],
"abb": ["abb", "bba"],
"abt": ["bat"],}

Далее сортируем слова внутри каждой группы. Например, группа с ключом aet становится:

["ate", "eat", "eat", "tea"]

Затем располагаем группы по количеству слов. Их размеры в результате: 1, 2, 2, 2 и 4.

Итоговый результат:

[["bat"],
["aab", "aba"],
["", ""],
["abb", "bba"],
["ate", "eat", "eat", "tea"],]

Оба вхождения слова eat и обе пустые строки сохранены. Группы aab и abb остаются разными, поскольку количество каждой буквы в них различается.
