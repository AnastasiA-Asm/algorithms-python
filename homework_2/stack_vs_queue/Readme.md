    Задание 1. Стек и очередь на основе связных списков

# Условие задачи

Нужно реализовать стек и очередь на основе односвязных списков без использования сторонних библиотек.

Для обеих структур реализованы добавление, удаление, просмотр элемента без удаления и проверка на пустоту.

## Объяснение решения

Для хранения элементов используется класс Node

Каждый узел содержит:
- value - значение элемента
- next - ссылку на следующий узел

Если следующего узла нет, nex равен None

Один узел можно представить так: [value | next]

Узлы соединяются друг с другом с помощью ссылок: [value | next] → [value | next] → [value | None]

### Реализация стека

Стек работает по принципу LIFO: элемент, добавленный последним, удаляется первым. Стек хранит ссылку top, которая указывает на верхний узел.

### Добавление элемента

Метод push(value):
1. Создаёт новый узел
2. Записывает в next нового узла ссылку на прежнюю вершину
3. Переносит top на новый узел

### Удаление элемента

Метод pop():
1. Проверяет, не пуст ли стек
2. Сохраняет значение верхнего узла
3. Переносит top на следующий узел
4. Возвращает сохранённое значение

### Остальные операции

Метод peek() возвращает значение верхнего элемента, но не удаляет его.

Метод is_empty() проверяет, равен ли top значению None.

## Реализация очереди

Очередь работает по принципу FIFO: элемент, добавленный первым, удаляется первым.

Очередь хранит две ссылки:
- head указывает на первый узел
- tail указывает на последний узел

### Добавление элемента

Метод enqueue(value):

1. Создаёт новый узел
2. Если очередь пустая, новый узел становится первым
3. Иначе новый узел присоединяется после текущего последнего узла
4. tail переносится на добавленный узел

### Удаление элемента

Метод dequeue():

1. Проверяет, не пуста ли очередь
2. Сохраняет значение первого узла
3. Переносит head на следующий узел
4. Возвращает сохранённое значение


### Остальные операции

Метод peek() возвращает значение первого элемента без удаления

Метод is_empty() проверяет, равен ли head значению None

# Оценка сложности

Пусть n — количество элементов в структуре.

| Структура | Операция | Время |
|---|---|---|
| Стек | push() | O(1) |
| Стек | pop() | O(1) |
| Стек | peek() | O(1) |
| Стек | is_empty() | O(1) |
| Очередь | enqueue() | O(1) |
| Очередь | dequeue() | O(1) |
| Очередь | peek() | O(1) |
| Очередь | is_empty() | O(1) |

Все операции выполняются за O(1), потому что программа уже хранит ссылки на нужные узлы. Для выполнения операций не требуется проходить по всему списку.

Общая память каждой структуры равна O(n), потому что для каждого элемента создаётся отдельный узел.

Дополнительная память одной операции равна O(1), так как за одну операцию создаётся не более одного нового узла и используется несколько обычных переменных.
